## USB Data Exchange Functions

- Data exchange is possible via the USB connection.
- The USB connection is located at the top left on the back side of the operating panel, behind a cover.
- The cover must always be closed and latched when the coffee machine is in operation.

### Functions available via USB:
- Load recipes
- Load cup symbols
- Save recipes
- Export counters
- HACCP export

The page lists five distinct functions that can be performed via USB: Load recipes, Load cup symbols, Save recipes, Export counters, and HACCP export.

## USB Data Exchange Functions (Page 57)

- Data backup: Saves machine and beverage data.

- Load language: Loads an alternative display language (if available).
- Firmware update: For service only.
