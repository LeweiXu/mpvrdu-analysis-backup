What Top of Funnel KPI's?
You need to focus on KPI's which can help you determine the effectiveness and performance of your activity and which levers (tactics / channels) you can pull to maximise ROI.
IRR = Initial Response Rate
CPIR = Cost Per Initial Response
CAR = Continued Action Rate
EA = End Actions
CPEA = Cost Per End Action
