- Wake On LAN
Values: Disabled, AC only, AC and Battery
Description: The network administrator can turn on a computer from a management console by using the Wake on LAN feature. If you select AC Only, the Wake on LAN feature is enabled only when the ac power adapter is attached. If you select AC and Battery, the Wake on LAN feature is enabled with any power sources.
Notes:
- The magic packet type Wake on LAN requires that the ac power is attached.
- The Wake on LAN feature does not work when the hard disk password is set.
• Wake On LAN from Dock
Values: Disabled, Enabled
Description: Enable or disable the Wake On LAN from Dock feature when the ThinkPad USB-C Dock or ThinkPad Thunderbolt 3 Dock is attached.
Note: The Wake on LAN from Dock feature does not work when the hard disk password is set.
