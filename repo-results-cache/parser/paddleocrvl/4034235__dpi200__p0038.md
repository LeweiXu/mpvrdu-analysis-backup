Use the digital tension to adjust the tension as appropriate for the material being sewn. (Refer to “Setting the tension value”.)

Furthermore, turn the tension nut (1) (sub-tension) to adjust the remaining length of upper thread to 35 - 40 mm, when the thread take-up lever is not used.

## Setting the tension value

Press the ☐ key (2) or the ☐ key (3) to change the tension value (4).

* The tension value which has been set will be applied the next time sewing is carried out.
