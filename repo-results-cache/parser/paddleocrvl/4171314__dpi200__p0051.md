#### 2.11.5 Netezza Data Warehouse Appliance

IBM Netezza (pronounced Ne-Tease-Ah) is a high-performance data warehouse appliances, used for advanced analytics applications such as enterprise data warehousing, business intelligence, predictive analytics, and business continuity planning.

Netezza’s architecture is a two-tiered system designed to quickly handle very large queries from multiple users.

The first tier is a high-performance Linux SMP host that compiles data query tasks received from business intelligence applications, and generates query execution plans. It then divides a query into a sequence of sub-tasks, that can be executed in parallel, and distributes the sub-tasks to the second tier for execution.

The second tier consists of one to hundreds of special blades, where all the primary processing work of the appliance is executed. The blades are intelligent processing nodes that make up the massively parallel processing (MPP) engine of the appliance. Each blade is an independent server that contains multi-core Intel-based CPUs. Each CPU core is teamed with its dedicated storage drive, gigabytes of random access memory and Netezza's proprietary hardware accelerator with a multiengine high-throughput field-programmable gate array (FPGA). These FPGAs are used for data decompression, data filtering and early SQL projections and restrictions. The nodes are configured in a shared-nothing environment, which means each of the CPUs has its own memory, and has no need to communicate with other nodes for record locking and lock resolution. The blade is composed of a standard IBM blade combined with a special Netezza Database FPGA Accelerator card which snaps alongside the blade. Each blade is, in turn, connected to multiple disk drives, processing multiple data streams in parallel.

Netezza employs industry-standard interfaces (SQL, ODBC, JDBC, OLE DB) and provides load times in excess of 2 TByte/hour and backup/restore data rates of more than 4 TByte/hour.

Netezza is not a part of the zBX Family of appliances, and connects to any data base system, including HP Superdome and Sun/Fujitsu M9000, via high speed Ethernet. What makes it special, is the unique integration witz z/OS DB2, using the z/OS “DB2 Analytics Accelerator”.
