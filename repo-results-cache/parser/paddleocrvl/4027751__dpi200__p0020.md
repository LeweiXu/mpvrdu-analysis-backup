The main functionalities include:

● Moving the servo to the desired position

• Controlling the speed of the servo

- Sending current position updates to the Message Queuing Telemetry Transport (MQTT) broker (more on MQTT in the Network Architecture chapter).

● Saving and retrieving angles from EEPROM memory.

At the start of the program, six instances of Servo are created and configured to represent the actual servos of the robotic arm.

Example of creating a base servo instance:

Servo baseServo (<pin number>, SERVOMIN_RED_BASE, SERVOMAX_RED_BASE, <speed (ms)>, BASE_SERVO_TOPIC);

Having created this configuration, the movement of each servo in the main event loop can be controlled. In order to keep all the servo motors moving synchronously, the methods controlling the servo should be kept in the main event loop, while other functions handle listening to new incoming data and setting the angles required to each servo.
