#### 2.3.5 Memory Optimization

Implementing all the libraries controlling the ethernet communication as well as the servo driver have taken up to 50 percent of the microcontroller’s memory and flash. Therefore, the main program should be memory efficient so as to not damage microcontroller.

The actions taken to optimize the memory were as follows:

- Use of specific data types according to need; for example, knowing “x” cannot have a value greater than 180 and less than 0 therefore, unsigned 8-bit integer data type (uint8_t) is used.

- Make use of the built-in EEPROM memory by saving the incoming angles to it. Unfortunately, the memory handles a maximum of 100,000 write cycles, so optimizations had to be made to ensure data is saved only when changed.

- Try not to use String data type, knowing the string amount of data needed for communication purposes an array of characters is used instead and extra measures are taken to ensure no overflow is occurred as the data that is transmitted can easily exceed the memory limit.

- Make use of JSON data type when sending bulk data.

Performing those optimizations results in a 20% increase in memory. Other extra measures can be taken to free up the memory by removing unwanted methods from the imported libraries, but because many methods are vital for the program to run, those steps were not taken into consideration.

### 2.4 Circuit Board

The circuit empowering the robotic arm consists of an Arduino UNO R3 microcontroller, an ethernet shield (W5100), a DC-DC Buck converter (LM2596 SMD DC-DC Step-down module), a servo driver (16-channel-pwm-servo-driver), two switches and a female power plug. Since the circuit board is simple some connections are hard wired through soldering and some are connected through prototype cables. The main power supply is a 12V / 3A regulated supply stepped down to feed a 6V servo driver (the maximum voltage required for the highest torque of each servo is 6 V) and 12 V to the Arduino UNO combined with the ethernet shield.
