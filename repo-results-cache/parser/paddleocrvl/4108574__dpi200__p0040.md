#### 7.2.2 Change Thin Client Local Administrator Account Password

Perform the following procedure to change the local Administrator account password.

## To change the Thin Client local Administrator account password

1. Log in to the local Administrator account. Refer to the section Local Administrator Account Login.

2. Disable the Write Filter. Refer to the procedure To disable the Write Filter. The Thin Client will restart and automatically log in to the local User account.

3. Log in to the local Administrator account.

4. Press [CTRL] [ALT] [DEL] and select Change a password.

5. Enter the user name as.\Admin.

6. Enter the old and new passwords and confirm the new password.

7. Press [Enter] to make the change and select OK to confirm.

8. Enable the Write Filter. Refer to the procedure To enable the Write Filter. The Thin Client will restart and automatically log in to the local User account.

9. Verify the new password by logging in to the local Administrator account using the new password.
