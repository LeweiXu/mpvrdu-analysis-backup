## 5 Configure Single Sign On

Users with 'System Administrator' permissions can set up the configuration for single sign on. Single sign on is a feature that allows users to log into cvi42 with their existing user credentials assigned by their organization's IT team. The admin port (default is 49697) must be used to access the LDAP Admin tab of the Preferences Menu.

The LDAP Admin Tab allows you to authenticate users against an Active Directory/LDAP server. In order to connect to an Active Directory/LDAP server, cvi42 needs the following information.

Location of the server (i.e. domain name or IP address)

Enable TLS\SSL communication

Username/password field is used to bind to your Active Directory/LDAP server.

The Username field is primarily used for specifying a domain name of the Active Directory/LDAP server. There are two ways of inserting the username. First, you can specify the username as domain name\username (e.g. "srclookup\jane"). Or you can specify the username as username@domain name (e.g. "jane@srclookup.com").

After you have inserted your password you can click on “Check name” to connect with your Active Directory/LDAP server. This allows you to verify the settings that you have entered.
