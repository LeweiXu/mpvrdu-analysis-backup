#### 2.11.4 zBX Appliances

As an alternative to blades with standard microprocessors, special blades called “appliances” are available. A zBX can initially accommodate regular blades with standard microprocessors, specifically x86 and PowerPC. They supported multiple operating systems, especially AIX, Windows and Linux, but in the future possibly Solaris, Xenix, UnixWare, SCO Unix and FreeBSD.

As an alternative, you can run specific applications more efficiently thanks to special hardware and software. An example is the family of WebSphere DataPower appliances.

DataPower Appliances contain many specialized hardware components, including ASIC-based Information Processing Systems, custom encrypted RAID drives, and (optional) hardware security modules.

DataPower Appliances operate a single digitally signed firmware containing an operating system and application stack. DataPower firmware runs on a flash storage device. It is a well performing and highly optimized platform to perform electronic messaging functions. As a result, users cannot run 3rd party applications on DataPower as they would on a traditional server and operating system. Instead of a traditional filesystem, DataPower runs with a collection of isolated virtual file systems called “Application Domains”. As a result, DataPower can appear to its client connections to be any type of network file system with any type of folders and links.

Another purpose of DataPower's firmware platform is security. The DataPower TCP and UDP network stack is expected to provide near-constant throughput under the most extreme and sophisticated DDoS and XSS network attacks.

The characteristic features of the appliances include

• WebSphere DataPower Integration Appliance XI50

• WebSphere DataPower XML Accelerator Appliance XA35

• WebSphere DataPower Message-Routing Appliance XM70

• WebSphere DataPower XML Security Gateway Appliance XS40

• WebSphere DataPower (B2B Business to Business) Gateway Appliance XB60
