### 4.2 Manage the Sensor Repository

The ODiSI is configured for use with Luna's strain, temperature High Definition Fiber Optic Sensing (HD-FOS) and SC Temperature sensors. Each sensor has a unique optical signature which is used to auto-identify a sensor connected to the ODiSI, and characterize its strain or temperature state. This reference file is called a sensor key and is contained in Luna-labeled flash drives shipped with each sensor. In order for an ODiSI to make measurements from a sensor, that sensor's key needs to be installed onto the controller prior to use. Once installed, these files are stored in the Sensor Repository on the controller.

Actions related to managing the Sensor Repository can be accessed from the "Manage Sensors" button. These actions include installing and uninstalling sensors, renaming sensors, deleting uninstalled sensors, as well as importing and exporting sensors.

### 4.3 View and Evaluate Sensor Status

Once a sensor is Identified and added to a particular Channel’s configuration, its performance can be viewed for evaluation through the “View” button beside each channel. The subsequent interface provides a look at the strain or temperature profile along the sensor. Other actions that can be accessed from this interface include creating and selecting a Tare, defining individual gages and segments for data logging and streaming, as well as Rekeying the sensor.

### 4.4 Set Up the ODiSI for Data Logging

Once satisfied with the sensor performance on each channel, the ODiSI can be set up for logging test data. Data logging rates, trigger settings, as well as data streaming settings are located in the Settings menu (accessed through the button 🔋), while the file naming fields are located at the top of the main software interface.

### 4.5 Run a Test

Clicking on the “Arm” button prepares the ODiSI for running a test. When data is being logged during a test, both the “Sensor Plot” and “Gage Plot” tabs will be active. The “Sensor Plot” tab allows viewing of the strain or temperature along all sensors, and the “Gage Plot” tab allows viewing of the strain or temperature measurements from select individual gage locations along all sensors, over time.

### 4.6 View Test Data

Test data is logged in binary files that are stored in the Test Data folder on the controller. Test data can be played back through the "Play Back Test Data" function and can be converted to human readable tab delimited.tsv files through the "Generate Test Data TSV Files" function. These TSV files can be opened in external programs such as Excel or Matlab for further data analysis.
