The filename for a font-description file important; it must be of the form “ $ \langle encoding\rangle\langle family\rangle.fd $”, where  $ \langle encoding\rangle $ is the lowercase version of the encoding name (typically “u” for symbol fonts) and  $ \langle family\rangle $ is the name of the font family. For LightBulb10, let’s call this “bulb”. Figure 5 lists the contents of ubulb.fd. The document “ $ \textsuperscript{ETEX}2_{\varepsilon} $ Font Selection” [LAT00] describes  $ \textsuperscript{DeclareFontFamily} $ and  $ \textsuperscript{DeclareFontShape} $ in detail, but the gist of ubulb.fd is first to declare a U-encoded version of the bulb font family and then to specify that a  $ \textsuperscript{ETEX}2_{\varepsilon} $ request for a U-encoded version of bulb with a (m)edium font series (as opposed to, e.g., bold) and a (n)ormal font shape (as opposed to, e.g., italic) should translate into a  $ \textsuperscript{ETEX} $ request for lightbulb10.tfm mechanically scaled to the current font size.

The final step is to write a  $ \mathtt{IATEx2}_{\varepsilon} $ style file that defines a name for each symbol in the font. Because we have only one symbol our style file,  $ \mathtt{lightbulb.sty} $ (Figure 6), is rather trivial. Note that instead of typesetting “A” we could have had  $ \mathtt{lightbulb} $ typeset “ $ \mathtt{char65} $”, “ $ \mathtt{char} $”41”, or “ $ \mathtt{char} $”101” (respectively, decimal, hexadecimal, and octal character offsets into the font). For a simple, one-character symbol font such as LightBulb10 it would be reasonable to merge  $ \mathtt{ubulb.fd} $ into  $ \mathtt{lightbulb.sty} $ instead of maintaining two separate files. ### 7.3 Math-mode spacing

Terms such as “binary operators”, “relations”, and “punctuation” in Section 3 primarily regard the surrounding spacing. (See the Short Math Guide for  $ \mathbb{E}^{T}\mathbb{E}^{X} $ [Dow00] for a nice exposition on the subject.) To use a symbol for a different purpose, you can use the  $ \mathbb{T}\mathbb{E}^{X} $ commands  $ \backslash $mathord,  $ \backslash $mathop,  $ \backslash $mathbin,  $ \backslash $mathrel,  $ \backslash $mathopen,  $ \backslash $mathclose, and  $ \backslash $mathpunct. For example, if you want to use  $ \backslash $downarrow as a variable (an “ordinary” symbol) instead of a delimiter, you can write “3 x + \backslash $mathord{ $ \backslash $downarrow}” to get the properly spaced “3x+ $ \downarrow $” rather than the awkward-looking “3x+ $ \downarrow $”. Similarly, to create a dotted-union symbol (“ $ \cup $”) that spaces like the ordinary set-union symbol ( $ \backslash $cup) it must be defined with  $ \backslash $mathbin, just as  $ \backslash $cup is. Contrast “A  $ \backslash $dot{ $ \backslash $cup} B” (“A $ \cup $B”) with “A  $ \backslash $mathbin{ $ \backslash $dot{ $ \backslash $cup}} B” (“A $ \cup $B”). See The  $ \mathbb{T}\mathbb{E}\mathbb{X} $book [Knu86a] for the definitive description of math-mode spacing.
