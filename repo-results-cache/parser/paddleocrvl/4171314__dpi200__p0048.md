#### 2.11.2 Blade Center Extension

Mainframes often serve as a platform for the development of new advanced technologies. An example are hybrid systems, consisting of a mainframe plus accelerators, for example on a cell processor. X86 or a PowerPC basis.

Mainframe applications often contain compute intensive parts that do not require typical mainframe characteristics like I/O performance or availability. In this case it is possible to offload parts of the application to a processor with a different architecture, for example x86 or PowerPC. This may be attractive whenever specific mainframe characteristics are not needed.

Demand for lower latency will drive co-location of hybrid transaction processing elements. A trail blazer development is Taikodom  $ [64] $. This is a Massively Multiplayer Online Role-Playing Game (MMORPG), which runs on the „Gameframe“ server of a company named Hoplon. The Gameframe server consists of a regular z10 mainframe, to which a large number of cell processor CPU chips are connected using Infiniband.

Data Base accelerators use a similar approach. The Tuebingen University Computer Science Department presently cooperates with the IBM Boeblingen development laboratory in the design of new hybrid architecture mathematical models and algorithms for use in the finance industry  $ [65] $.

Distributed servers consist in the majority of cases of assemblies, which are called "blades". A blade is a printed circuit board (similar to a PC motherboard), on which there are typically two microprocessor chips, usually with 4 or 8 CPU cores/chip. Further a blade includes slots for memory DIMMs (Dual Inline Memory Module), ASIC chips for integration, for Ethernet and Serial SCSI or Fibre Channel SCSI connections, and possibly slots for one or two 2 $ ^{1/2} $-inch hard drives which store the operating system. The blades are equipped with x86 or PowerPC processors. On each blade run an operating system such as Windows, Linux, and AIX.

Blades are housed in a blade chassis (Blade Enclosure, IBM calls it "BladeCenter"). A blade enclosure contains a number of blades. Each blade typically runs its own operating system. Furthermore, the blade enclosure offers additional features such as power, cooling, Ethernet networking, disk storage ports (often via Fibre Channel SCSI) and management functions. An IBM BladeCenter holds up to 14 IBM blades.

The "System z BladeCenter Extension" (zBX) is a grouping of one or more specially optimized IBM BladeCenters that communicate over a secure, private high-performance network with a zEnterprise central processor complex (CPC) - either zEC12, z196 or Z114. The zBX is usually placed next to the system z computer. The data connections between the two units are not externally accessible. A zBX can hold a mixture of x86 and PowerPC blades. In addition there are special blades, called appliances. These are high performance special processors for specific workloads (eg XML or crypto processing).

The combination of one or more system z computer with one or more zBX is referred to as a zBXs zEnterprise system. The administration of a zEnterprise System is a new component, the zEnterprise Unified Resource Manager with System z maintenance standards.
