At the start of the program, the Arduino connects to the broker and subscribes to the required topics and subtopics, if this connection is broken the Arduino halts the main event loop to reconnect to the broker. In order to keep the connection alive in a non-blocking manner, the desired network functions (keeping the connection alive and listening to data from certain topics) are implemented in the main event loop. The 3 major topics to facilitate the data needed are arm, status, and set; the arm topic is used by the Servo class to send real-time values to a specific topic inputted in the object parameters (created from Servo). Furthermore, the status topic is used to stop or resume the operations of the Arduino, it is also used to know if the servos have reached their desired positions or not. Lastly, the set topic is used to set the angles of the servos. The data sent to this topic is in a JSON format.

An example of the JSON format used to set the servo angles is shown below:

{
    "base": 90,
    "shoulder": 45,
    "elbow": -65,
    "pitch": -45,
    "yaw": 90,
    "hand": 160
}

This JSON data is decoded using the built-in ArduinoJson library and is made into an accessible dictionary like data type. For example, to access the base angle from the buffer:

jsonBuffer["base"]
