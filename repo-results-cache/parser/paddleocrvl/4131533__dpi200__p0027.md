### 6.2 Manage the Sensor Repository

The detection of the correct sensor on each channel depends on the presence of the sensor key within the instrument's Sensor Repository. Click on "Manage Sensors" on the main software interface to access the sensor management window. The sensor management window provides the ability to install new sensors, delete unused sensors, and rename installed sensors.

Serial Number: Lists the serial numbers of all sensors installed on the controller.

Name: Lists the custom names associated with all sensors installed on the controller.

Rename: Click to change the sensor name.

Uninstall: Click to uninstall the sensor from the system. Uninstalling sensors reduces the time for sensor identification by removing them from the list used to identify sensors. It does not remove sensor data from the system’s memory.

Rekey: Select the specific Rekey to use with the listed sensor.

Install Luna Sensor Key: Click to install a sensor from a Luna-provided flash drive containing the sensor key.

Delete Uninstalled Sensors: Click to delete uninstalled sensors.

Note: This will permanently remove the sensor and any associated data from the system’s memory.

Import Sensors: Sensor Tares, Rekey information, Gages, and Segments associated with each sensor key can be moved from controller to controller. Click “Import Sensors” to import the entire sensor key folder that had been exported from a different controller.

Export Sensors: Click to export the entire sensor key folder including Sensor Tares, Rekey information, Gages, and Segments to a flash drive or CD drive.
