### 7.6 Verify DHCP Server Status

The system uses redundant DHCP Servers, hosted on the DC1 and DC2 VMs, to provide DHCP services to the Thin Clients. The Thin Clients rely on DHCP to get their IP addresses. If the Thin Client cannot access the DHCP Servers, the Thin Client will be unable to communicate on the network.

## ➢ To verify DHCP Server status

1. Establish a remote session with the DHCP Server VM.

2. Verify that the DHCP Server service is running.

3. Repeat for both the DC1 and DC2 VMs.
