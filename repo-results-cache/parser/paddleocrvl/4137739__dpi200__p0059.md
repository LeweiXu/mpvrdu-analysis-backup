#### 3.4.5 Safety Relay

This relay protects the machine against program malfunctions by disconnecting the 12 Vcc and 24 Vcc power inputs.

The machine activates this relay and deactivates it when it detects that it is performing incorrectly. This keeps the machine from expelling all of the product or admitting credit without being able to make any selections, etc.

The Control Card governs this relay which is situated in the I/O Card through the U3 and using the U8.
