#### 2.3.4 High-level Software Architecture Diagram

On system boot up, the microcontroller initializes the servo driver, the ethernet connection, and creates 6 Servo instances. It then reads the last set angles from the EEPROM memory and sets the angles of the servos accordingly as shown in Figure 16.

In the main event loop, methods are used to keep the connection alive and listen to interrupt signals or new angles signals. If new angles are set, the designated servo will be driven in the main event loop in a non-blocking manner.
