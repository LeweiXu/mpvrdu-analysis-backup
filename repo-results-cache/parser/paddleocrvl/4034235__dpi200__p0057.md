### 6 -5. Using cycle programs

Sewing patterns that have been recorded in user programs can be recorded in up to 30 cycle programs (C01 to C30). One cycle program can contain up to a maximum of 50 steps (St1 to St50).

When sewing the sewing patterns in a certain order, it can be useful to record them in a cycle program beforehand.
