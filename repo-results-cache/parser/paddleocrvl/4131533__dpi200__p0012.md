## 4 Software Overview

This chapter provides a description of the functionalities available in the ODiSI 6 user software. Instructions for how to quickly set up a test and log data comes next (Chapter 5 Software Quick Start Guide). Following that is a detailed explanation of all the ODiSI 6 software functionalities (Chapter 0 Using the ODiSI 6 Software).

The functionalities provided by the software relate to the following main actions:

1. Operational parameters

2. Manage the sensor repository

3. View and evaluate sensor performance

4. Set up the ODiSI for data logging

5. Run a test

6. View test data

These actions are labeled in Figure 4-1 which shows the main ODiSI 6 software interface.

Once completed, the main user interface will be displayed, showing the status of the system as well as each channel on the ODiSI.
