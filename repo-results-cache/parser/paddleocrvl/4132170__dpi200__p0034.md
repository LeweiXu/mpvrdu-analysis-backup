3.2. MONOIDAL REPRESENTATION. We now return to the main thread of the paper and consider the notion of monoidal representation for a Cartesian storage category. Our objective is to show that a Cartesian storage category with monoidal representation is precisely the coKleisli category of a monoidal storage category. To achieve this, however, we must first take a detour to develop the notion of tensor representation. Recall that a basic intuition for a tensor product is that it should represent bilinear maps: clearly this intuition can be expressed in any category with a system of linear maps:

##### 3.2.1. DEFINITION

(i) In any Cartesian category a system of linear maps has monoidal representation in case for each X and Y there is an object  $ X \otimes Y $ and a bilinear map  $ \varphi_{\otimes}: X \times Y \to X \otimes Y $ such that for every bilinear map  $ g: X \times Y \to Z $ in X there is a unique linear map in X making the following diagram commute:

 $$ \begin{array}{l}X\times Y\xrightarrow{g}Z\\\varphi\otimes\left\downarrow\atop\left.\right.\quad g_{\otimes[A]}\end{array} $$ 

(ii) In any Cartesian category a system of linear maps has strong monoidal representation in case for each X and Y there is an object  $ X \otimes Y $ and a bilinear map  $ \varphi_{\otimes}: X \times Y \to X \otimes Y $ such that for every bilinear map  $ g: X \times Y \to Z $ in  $ X[A] $ there is a unique linear map in  $ X[A] $ making the above diagram commute. Note that this means in X we have the diagram:

 $$ \begin{array}{c}A\times X\times Y\xrightarrow{g}Z\\\left.\begin{array}{c}\\1\times\varphi_{\otimes}\\\end{array}\right\downarrow\\A\times(X\otimes Y)\end{array} $$ 

(iii) A system of linear maps is unit representable in case there is a linear map  $ \varphi_{\top}\colon1\to\top $ such that in X for each point  $ p\colon1\to Z $ there is a unique linear point  $ p_{\top}\colon\top\to Z $ making

 $$ \varphi_{\top}\xrightarrow[\top]{1}\xrightarrow{p}Y $$ 

commute.

(iv) A system of linear maps is strongly unit representable in case it is representable in each simple slice. This means there is a unique  $ p^{\top[A]} $ making

 $$ \begin{array}{c}A\times1\xrightarrow{p}Y\\1\times\varphi_{\top}\\\left\downarrow\right.\\A\times\top\end{array} $$
