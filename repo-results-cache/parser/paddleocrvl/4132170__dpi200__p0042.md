PROOF. Once we have a codereliction we have a split pair

 $$ S^{2}(A)\otimes S^{2}(B)\xrightarrow[\substack{\frac{\epsilon\otimes\epsilon}{S(\epsilon)\otimes S(\epsilon)}}]{}\overset{\eta\otimes\eta}{\underset{}{\longrightarrow}}S(A)\otimes S(B) $$ 

whose absolute coequalizer is the splitting of  $ \epsilon\eta\otimes\epsilon\eta $. Thus, when linear idempotents split one has basic monoidal representation. As this coequalizer is absolute in the whole storage category it is necessarily preserved by products and so the monoidal representation is strong, hence persistent.

In particular, as we shall discover in Section 4, a Cartesian differential storage category always has a codereliction  $ \eta=\langle1,0\rangle D_{\times}[\varphi] $ which is linear (in the differential sense) and splits  $ \epsilon $. Thus, in these examples it suffices for linear idempotents (in simple slices) to have linear splittings. This can always be formally arranged by splitting the linear idempotents.

3.4. MONOIDAL STORAGE CATEGORIES WITH AN EXACT MODALITY. We now observe that in a Cartesian storage category, which has monoidal representation, the linear maps form a monoidal storage category:

3.4.1. PROPOSITION. In any Cartesian storage category with monoidal representation, the subcategory of linear maps is a monoidal storage category.

PROOF. We have already observed that there is a monoidal comonad present on the linear maps. In addition, when both a persistent classification and representation is present there is a natural isomorphisms  $ s_{\otimes}\colon S(X\times Y)\to S(X)\otimes S(Y) $ and an isomorphism  $ s_{\top}\colon\top\to S(1) $ constituting an iso-comonoidal structure for the functor  $ S\colonX\toX $ from X with product to X with tensor: this is the storage isomorphism.

This follows immediately from the fact that

 $$ X\times Y\xrightarrow{\varphi\times\varphi}S(X)\times S(Y)\xrightarrow{\varphi\otimes}S(X)\otimes S(Y)\quad\begin{array}{c}and\\ \left.\begin{array}{c}s_{S\otimes}^{-1}\\ \end{array}\right|_{S(X)\times Y}\end{array}\quad\begin{array}{c}X\times Y\xrightarrow{\varphi}S(X\times Y)\\ \left.\begin{array}{c}\left.\begin{array}{c}\varphi\\ \end{array}\right|_{(S\times\varphi)\varphi\otimes}s_{S\otimes}\\ \end{array}\right|_{S(X)\otimes S(Y)} $$ 

have the same universal property. Similarly  $ \top $ and  $ S(1) $ have the same universal property. That this constitutes a storage transformation is straightforward to check.
