### 7.2 Change Local Thin Client Account Passwords

Thin Clients come from the factory with well-known default local User and Administrator account passwords. The default password for both accounts is DellCCCvdi. For security, the default passwords should be changed to reduce the risk of unauthorized users gaining access to the Thin Client terminals at the site.

#### 7.2.1 Change Thin Client Local User Account Password

Perform the following procedures to change the local User account password and update the auto logon password setting with the newly created password.

## ➢ To change the local User account password

1. Log in to the local Administrator account. Refer to the section Local Administrator Account Login.

2. Disable the Write Filter. Refer to the procedure To disable the Write Filter. The Thin Client will restart and automatically log in to the local User account.

3. Log in to the local Administrator account.

4. From the Control Panel, select User Accounts, then select Manage User Accounts.

5. In the User Accounts dialog box, select User, then click Reset Password.

6. In the Reset Password dialog box, enter the new password and confirm the new password, then click OK.

7. In the User Accounts dialog box, click OK.

8. Click the X to close the User Accounts window.

## To update auto logon password setting

1. Launch the Dell Thin Client Application and select Auto Logon.

2. Verify that Enable Auto Logon is selected (checked).

3. In the Default Password field, enter the new User account password and click Apply.
