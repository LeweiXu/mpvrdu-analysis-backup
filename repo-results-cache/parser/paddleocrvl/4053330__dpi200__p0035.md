TITLE: Place of Service [lines 1–6]

INSTRUCTIONS: In 24B, enter the appropriate two-digit code from the Place of Service Code list for each item used or service performed. The Place of Service Codes are available at: www.cms.gov/Medicare/Coding/place-of-service-codes/Place_of_Service_Code_Set.html.

DESCRIPTION: The “Place of Service” Code identifies the location where the service was rendered.

FIELD SPECIFICATION: This field allows for the entry of 2 digits in the unshaded area.
