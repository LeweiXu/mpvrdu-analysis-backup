### 5.6 View Test Data

1. Play back test data.

a. From the Menu bar, click on Tools > Play Back Test Data.

b. Select the correct Test Data file.

c. Play back or scroll through the test data using the navigation buttons.

2. Convert binary test data into ascii format.

a. From the Menu bar, click on Tools > Generate Test Data TSV File.

b. Select the correct Test Data file(s). Add them individually or in a batch. Click "Save".

c. Select the folder to which TSV files will be written. Click "Save".

d. Once file conversion is complete, this status will be indicated in a pop-up window.
