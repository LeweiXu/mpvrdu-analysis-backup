#### 2.11.6 DB2 Analytics Accelerator for z/OS

The DB2 Analytics Accelerator is a high-performance Analytics Accelerator appliance for IBM System z, combining z/OS DB2 properties with the Netezza hardware accelerated analytics functions. It blends System z and Netezza technologies to deliver mixed workload performance for complex analytic needs. The IBM DB2 Analytics Accelerator is a workload optimized appliance enabling the integration of business insights into operational processes driving winning strategies

The DB2 Analytics Accelerator uses copies of DB2 for z/OS database tables that are stored in the Netezza accelerator. This offers the best of both worlds: top DB2 for z/OS performance for transactional queries and industry-leading IBM Netezza performance for analytical queries. Queries are performed by the Netezza hardware.

The DB2 Analytics Accelerator with its Netezza hardware is fully integrated into z/OS DB2. A complete transparency is achieved for applications that pass queries to DB2 for z/OS. Users and applications see just one DB2 for z/OS interface.

It runs complex queries up to 2000 times faster while retaining single record lookup speed and eliminates costly query tuning while offloading query processing.
