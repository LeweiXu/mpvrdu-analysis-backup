## Abstract:-

This paper presents the speed control of DC Motor using fuzzy logic controller based on chopper devices mainly boost converter. The DC motor consist of armature and field winding in which armature winding is controlled by using boost converter which is triggered by fuzzy logic controller which consist of 3x3 rule and the input are change in error and rate of change in error and output is firing angle. The fuzzy logic controller gives smooth, reliable, efficient speed controlling of DC motor. The complete system is designed with SIMULINK MODEL 2KW DC motor.
