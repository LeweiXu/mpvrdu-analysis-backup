### 3. - Component Description

### 3.1 Power Input

It has a double function:

✓ Provide necessary voltage for the operation of the rest of the machine.

✓ Protect the electrical unit against any surge generated in the power source or over-consumption by the machine itself.

It consists of the following elements:

✓ Illuminated Bipolar Switch  

✓ Power Source Protection Fuse  

✓ Transformer





✓ Power Card

Illuminated Bipolar Switch
