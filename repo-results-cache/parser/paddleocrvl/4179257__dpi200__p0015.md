## Entering and editing example

Entering “DX spot 1” in the Memory channel 2

### 1. Open the MEMORY screen

MENU » MEMORY

2. Touch the memory channel 2 for 1 second.

<div style="text-align: center;"><img src="imgs/img_in_image_box_162_611_587_809.jpg" alt="Image" width="25%" /></div>


• Opens the QUICK MENU.

You can also open the QUICK MENU by touching this key.

3. Select “Edit Name.”

<div style="text-align: center;"><img src="imgs/img_in_image_box_161_911_586_1153.jpg" alt="Image" width="25%" /></div>


• Opens the MEMORY NAME screen.

<div style="text-align: center;"><img src="imgs/img_in_image_box_610_913_774_1142.jpg" alt="Image" width="9%" /></div>
