## Summary

1) Consumer company speed and scale requirements driving efficiencies in Big Data storage and analytics

2) Quantity of machine data vastly increasing (examples: networked sensor data from mobile phones and GPS devices)

3) Move away from batch to real-time

4) Cloud services opening Big Data to all

5) New and broader number of data sources being meshed together

6) Big Data Apps (BDAs) means using Big Data is faster and easier
