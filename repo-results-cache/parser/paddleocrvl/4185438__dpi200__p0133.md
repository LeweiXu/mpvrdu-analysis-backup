2. if dom  $ f = \operatorname{cod} g $ we can compose the functions,

3. function composition is associative,

4. for each set X, there is an identity function  $ id_{A}: X \to X $, and this identity function has the property  $ f \circ id_{A} = f $ and  $ id_{A} \circ g = g $.

Notice that group homomorphisms also satisfy all of these conditions.

### Definition 4.2

A category C consists of a set of objects, O; a set of arrows or morphisms A, two functions

 $$ \operatorname{cod}:\mathcal{A}\to\mathcal{O}\qquad and\qquad\operatorname{dom}:\mathcal{A}\to\mathcal{O} $$ 

which assign to each arrow an object called, respectively, the domain and codomain of the arrow; a function

 $$ i d:\mathcal{O}\to\mathcal{A}, $$ 

which assigns to each object A an identity arrow  $ id_{A} $; and a composition operation that assigns each to pair of arrows  $ (\alpha, \beta) $ with dom  $ \alpha = \operatorname{cod} \beta $ an arrow  $ \gamma = \alpha \circ \beta $ with  $ \operatorname{cod} \gamma = \operatorname{cod} \alpha $ and  $ \operatorname{dom} \gamma = \operatorname{dom} \beta $.

We will write  $ f : A \to B $ to denote that an arrow f has domain A and codomain B, or diagramatically, write:

 $$ A\to B $$ 

These have to satisfy the following axioms:

(i) Associativity: if  $ f : B \to A $,  $ g : C \to B $, and  $ h : D \to C $, then

 $ (f \circ g) \circ h = f \circ (g \circ h) $,

(ii) Identity: for any  $ f: A \rightarrow B $,  $ f \circ id_A = f $; and for any  $ g: B \rightarrow A $,

 $ id_A \circ g = g, $

Notice that these axioms are very similar to the definition of a group, but with added complexity because of the necessity of dealing with the domains and codomains, and with no inverse axiom.
