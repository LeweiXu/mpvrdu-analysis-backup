### 5.4 Set Up the ODiSI for Data Logging

1. Set up data file properties.

a. Ensure “Save test data to file” is checked.

b. Fill in the “Test Name” and “Notes” fields.

c. Click “Browse” to select a folder.

2. Set up data logging rate

a. Click the Settings button (☐).

b. In the “Filter and Downsample” tab, click the check box next “Temporal Downsampling Factor” and specify the “Temporal Downsampling Factor” to down-sample from the full data rate.
