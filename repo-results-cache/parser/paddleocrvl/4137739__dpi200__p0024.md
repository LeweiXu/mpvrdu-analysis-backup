### 2.5 Temperate and Relative Humidity

In order to expect optimum performance from the machines, there environment must meet the following conditions:

✓ Room temperature: Between  $ 0\ °C $ and  $ 32\ °C $.

✓ Relative humidity : Between 35% and 95%.

These figures are not valid if the machine is exposed to direct sunlight.

### 2.6 Operational Incline

Both frontal and lateral inclination should not surpass  $ 2^{\circ} $. This requirement is fundamental for the correct functioning of the coin system.

### 2.7 Sound Level

The sound level of these machine never reaches 70 dB(A).
