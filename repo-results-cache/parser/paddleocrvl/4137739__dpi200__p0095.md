### 4.5 Test Function

This function verifies the operation of all the ele\-ments composing the machine.

When the machine is in operation, this function may be accessed by pressing the red programming button for four seconds until the message "TEST FUNCTION" appears. The different elements of the machine will now begin to be tested. To change the TEST from one element to another, press the coin return button.
