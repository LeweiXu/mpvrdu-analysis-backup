# 3.1.1 Illuminated Bipolar Switch and the Power Source

When the unit is connected to a biphasic electrical network the voltage is applied to the bipolar switch. When this switch is deactivated, the machine remains completely disconnected from the network and when it is activated the two phases become directly applied in the machine.

Between the machine and the bipolar switch a 10 amp switch is found whose function is to protect the machine from possible short circuits which the components directly fed by the network might produce such as: the cold group, illumination, the container fan or the power source transformer.
