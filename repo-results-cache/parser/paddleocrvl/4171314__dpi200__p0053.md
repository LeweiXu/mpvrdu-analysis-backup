The new Optimizer component of z/OS DB2 decides whether an SQL query is processed on z/OS, or is passed to the DB2 Analytics Accelerator (Netezza).

The deep integration of Netezza in z/OS DB2 differentiates the DB2 Analytics Accelerator from other data warehouse solutions.
