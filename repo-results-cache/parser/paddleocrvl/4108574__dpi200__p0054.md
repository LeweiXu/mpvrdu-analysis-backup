#### 7.14.3 Revoke Unused Device CAL

## ➢ To revoke an unused Device CAL

1. Launch RD Licensing Manager.

2. Expand the server node and select the Installed node to display the details for each installed RDS Per Device CAL and to which device it is allocated.

<div style="text-align: center;"><img src="imgs/img_in_image_box_201_358_1593_877.jpg" alt="Image" width="81%" /></div>


If a device is no longer available (for example, a Thin Client terminal has failed and has been replaced by a new terminal), the RDS Per Device CAL allocated to it can be revoked. Revoking a license returns it to the available license pool, making it available to be reassigned to a new device.

Note Additional RDS Per Device CAL licenses can be purchased and added to the available license pool if required by the site.
