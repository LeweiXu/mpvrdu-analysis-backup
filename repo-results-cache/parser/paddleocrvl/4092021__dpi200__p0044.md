#### 5.10.6 Setting rotate

1 Select the area you want to set the rotate with the mouse and right-click or click ☐ to show the drop-down menu.

<div style="text-align: center;"><img src="imgs/img_in_image_box_232_722_1419_1068.jpg" alt="Image" width="71%" /></div>


<div style="text-align: center;">2 Click [Rotate] to show the dialog for the rotate settings.</div>


<div style="text-align: center;"><img src="imgs/img_in_image_box_235_1137_685_1552.jpg" alt="Image" width="27%" /></div>


<div style="text-align: center;">3 In the dialog above, select the start point (left side) and end point (right side) to set how much you want to rotate, and click OK.</div>


<div style="text-align: center;">The rotate is set to the selected area.</div>


<div style="text-align: center;"><img src="imgs/img_in_image_box_233_1737_1416_1958.jpg" alt="Image" width="71%" /></div>


<div style="text-align: center;">* You can copy, adjust length, and delete the rotate settings in the same way as described in the color settings. Please refer to 5.9.2 Color settings.</div>
