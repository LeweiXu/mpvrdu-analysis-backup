3.1.5. LEMMA. In a linear category there is the following implication of commutative diagrams

 $$ \begin{array}{c}S(A)\xrightarrow{f}S(B)\\ \left.\begin{array}{c}\left.\delta\right\vert\\ S^{2}(A)\xrightarrow[S(f)]\left.\begin{array}{c}\left.\delta\right.\\ \left.\delta\right.\end{array}\right.\\ S^{2}(B)\end{array}\right.\\ \left.\begin{array}{c}\\ S(A)\xrightarrow{f}S(B)\\ \left.\begin{array}{c}\left.\Delta\right\vert\\ S(A)\otimes S(A)\xrightarrow[f\otimes f]{}\left.\begin{array}{c}\left.\Delta\right.\\ \left.\Delta\right.\end{array}\right.\\ S(B)\otimes S(B)\end{array}\right.\end{array}\right.\end{array} $$ 

PROOF. We use the fact that  $ \delta $ is a morphism of comonoids and is a section (with retraction  $ \epsilon $). This means the lower diagram commutes if and only if  $ f\Delta(\delta\otimes\delta)=\Delta(f\otimes f)(\delta\otimes\delta) $ but for this we have:

 $$ \begin{align*}f\Delta(\delta\otimes\delta)\quad&=\quad f\delta\Delta=\delta S(f)\Delta=\delta\Delta(S(f)\otimes S(f))\\&=\quad\Delta(\delta\otimes\delta)(S(f)\otimes S(f))=\Delta((\delta S(f))\otimes(\delta(S(f))=\Delta((f\delta)\otimes(f\delta))\\&=\quad\Delta(f\otimes f)(\delta\otimes\delta).\end{align*} $$ 

Note that this immediately means that if f is a coalgebra morphism, it is also then a cononoid morphism, and so Bierman’s original definition of a linear category corresponds to ours (modulo the absence of closedness).

3.1.6. THEOREM. A monoidal storage category is a linear category and conversely a linear category with products is a monoidal storage category.

PROOF. We rely on a combination of [S04] and [M02] to provide the proof. In particular, the monoidal structure of the monad is given by.

 $$ \begin{array}{rcl}\top\xrightarrow{m_{\top}}S(\top)&=&\top\xrightarrow{s_{1}^{-1}}S(1)\xrightarrow{\delta}S^{2}(1)\xrightarrow{S(s_{1})}S(\top)\\S(A)\otimes S(B)\xrightarrow{m_{\otimes}}S(A\otimes B)&=&S(A)\otimes S(B)\xrightarrow{s_{2}^{-1}}S(A\times B)\xrightarrow{\delta}S^{2}(A\times B)\\&&&\xrightarrow{S(s_{2})}S(S(A)\otimes S(B))\xrightarrow{\epsilon\otimes\epsilon}S(A\otimes B)\end{array} $$ 

The converse requires checking that a linear category with products provides a storage isomorphism. The fact that there is a coalgebra modality is part of the data above. What remains is to prove that the induced storage transformation is an isomorphism and this is in the literature above.
