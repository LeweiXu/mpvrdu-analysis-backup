## 5 Dingbats

Dingbats are symbols such as stars, arrows, and geometric shapes. They are commonly used as bullets in itemized lists or, more generally, as a means to draw attention to the text that follows.

The pifont dingbat package warrants special mention. Among other capabilities, pifont provides a L $ ^{T} $EX interface to the Zapf Dingbats font (one of the standard 35 PostScript fonts). However, rather than name each of the dingbats individually, pifont merely provides a single  $ \backslash $ding command, which outputs the character that lies at a given position in the font. The consequence is that the pifont symbols can't be listed by name in this document's index, so be mindful of that fact when searching for a particular symbol.
