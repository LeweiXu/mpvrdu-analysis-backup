### 4. - Troubleshooting

Malfunctions are divided into two groups:

✓ Malfunctions "detected" by the autocheck system incorporated into the machine program

✓ Malfunctions "undetected" by the autocheck system

### 4.1 Detected Malfunctions

This section will indicate the message shown in the display, its possible cause, and the defective component in order of probability.

The possible "cause" is determined by the checks which the Control Card performs of the different peripherals according to the program stored in the Eprom memory.

These malfunction can be classified into two groups:

✓ TOTAL: The machine becomes completely inoperable, showing "OUT OF ORDER" in the display

✓ PARTIAL: The machine continues operating with some element malfunctioning without showing any message
