### 2.6 Connect Thin Client to PDH Network

To connect the Thin Client to the PDH network and configure the connection: connect the client Ethernet port to the PDH network.

#### 2.6.1 Configure Private Network

➢ To configure a private network

1. Click on the Ethernet icon in the system tray of the task bar and select Network Settings.

<div style="text-align: center;"><img src="imgs/img_in_image_box_612_468_985_727.jpg" alt="Image" width="21%" /></div>


Network settings

2. From the Settings dialog box, click the Ethernet connection (HMI.local).

<div style="text-align: center;"><img src="imgs/img_in_image_box_259_847_1336_1358.jpg" alt="Image" width="63%" /></div>


3. Set the Make this PC discoverable option to On to enable the Private network mode.

### HMI.local

Make this PC discoverable

Allow your PC to be discoverable by other PCs and devices on this network. We recommend turning this on for private networks at home or work, but turning it off for public networks to help keep your stuff safe.
