## Abstract:-

Proposed CDSS is to provide assistance to technicians. With this approach, patient data is presented with the help of CDSS and used to analyze and diagnose with the problem. It works using CBR (Case Base Reasoning) and using DDSS (Diagnosis Decision Support System). In this paper existing CDSS has been modified which is language friendly, maintain large data base, giving it a shape of an app, making it more secure so that no one can make fool of any patient and build up a large involvement so that worldwide doctors can work on it and can give better advice to any patient from anywhere.
