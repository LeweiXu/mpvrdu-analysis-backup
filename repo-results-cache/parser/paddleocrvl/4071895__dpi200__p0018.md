#### 1.2.2 Type generating series

Let us now consider the enumeration of isomorphism types of F-structures. We may restrict ourselves to structures on sets of the form  $ U = \{1, 2, \ldots, n\} = [n] $. One defines an equivalence relation  $ \sim $ on the set F[n] by setting, for  $ s, t \in F[n] $,

 $ s \sim t $ if and only if s and t have the same isomorphism type.

In other words (see Definition 1.4),  $ s \sim t $ if and only if there exists a permutation  $ \pi : [n] \longrightarrow [n] $ such that  $ F[\pi](s) = t $. By definition, an isomorphism type of F-structures of order n is an equivalence class (modulo the relation  $ \sim $) of F-structures on [n]. Such an equivalence class is also called an unlabeled F-structure of order n. Denote by  $ \mathrm{T}(F_n) $ the quotient set  $ F[n]/\sim $, of types of F-structures of order n and let

 $$ \mathrm{T}(F)=\sum_{n\geq0}\mathrm{T}(F_{n}). $$
