### 7.8 Write Filter

When enabled on Windows 10 Thin Clients, the Write Filter prevents changes from being made to the Thin Client. Any changes made while the Write Filter is enabled are lost when the Thin Client is restarted. Changes are only persisted when the Write Filter is disabled.

#### 7.8.1 Write Filter Status

The Write Filter status is displayed in the system tray. A green circle icon indicates that the Write Filter is enabled (ON), and a red circle icon indicates that the Write Filter is disabled (OFF).

#### 7.8.2 Enable/Disable Write Filter

## ➢ To enable the Write Filter

1. Log in to the local Administrator account. Refer to the section Local Administrator Account Login.

2. Right-click the Dell Wyse WF Enable desktop icon and select Run as administrator.

<div style="text-align: center;"><img src="imgs/img_in_image_box_731_903_862_1047.jpg" alt="Image" width="7%" /></div>


Enable Write Filter Desktop Icon

The Thin Client will restart, and the Write Filter will be enabled after the reboot completes.

## ➢ To disable the Write Filter

1. Log in to the local Administrator account. Refer to the section Local Administrator Account Login.

2. Right-click the Dell Wyse WF Disable desktop icon and select Run as administrator.

<div style="text-align: center;"><img src="imgs/img_in_image_box_728_1425_866_1577.jpg" alt="Image" width="8%" /></div>


Disable Write Filter Desktop Icon

The Thin Client will restart, and the Write Filter will be disabled after the reboot completes.

3. In the Unified Write Filter dialog box, click OK to acknowledge the Write Filter disabled warning.
