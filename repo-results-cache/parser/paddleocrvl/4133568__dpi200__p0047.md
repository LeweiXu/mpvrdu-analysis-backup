## Common Cache Coherency Protocol: MOESI (snoopy protocol)

• Each block in each cache is in one of the

following states:

– Modified (in cache)

– Owned (in cache)

– Exclusive (in cache)

– Shared (in cache)

– Invalid (not in cache)
