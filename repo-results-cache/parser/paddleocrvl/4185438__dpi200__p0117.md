### Proposition 3.56

Let G be a finite group. The Cayley graph with generating set taken to be all of G is the complete graph on  $ |G| $ vertices.

Proof:

Given any pair of vertices x, y, the element  $ g = y^{-1}x $ is in the generating set G, and  $ yg = yy^{-1}x = x $, so there is an edge joining x and y. Hence the Cayley graph is a complete graph.

With careful selection of the generating set, however, the Cayley graph can reveal a lot about the structure of the group.

### Proposition 3.57

Let G be a group, and S a finite set which generates G. The Cayley graph of G with generating set S has the following properties:

(i) the graph is connected.

(ii) every vertex is an end of exactly  $ \left|S\cup S^{-1}\right| $ edges

Proof:

(i) Every element x can be written as a product  $ x = x_{1}x_{2}\cdots x_{n} $ of elements  $ x_{k} \in S \cup S^{-1} $, so  $ e, x_{1}, x_{1}x_{2}, \ldots, x_{1}x_{2} \cdots x_{n-1}, x $ is a path from e to x. So the Cayley graph is connected.

(ii) Given any  $ x \in G $, if we consider the set

 $$ X=\{x g:g\in S\cup S^{-1}\}, $$ 

then we note that if  $ xg_{1}=xg_{2} $, the cancellation law says that  $ g_{1}=g_{2} $. Therefore every edge  $ (x,xg) $ is distinct, and  $ |X|=|S\cup S^{-1}| $. Furthermore, if there is some y such that  $ (y,x) $ is an edge, then x=yg for some  $ g\in S\cup S^{-1} $, so  $ y=xg^{-1}\in X $. So X is exactly the set of all vertices connected to x by one edge. So x is an end of exactly  $ |S\cup S^{-1}| $ edges.
