## Open MP Pitfall #2: Sharing Issues

## • Consider the following loop:

#pragma omp parallel for
for(i=0; i<n; i++) {
    temp = 2.0*a[i];
    a[i] = temp;
    b[i] = c[i]/temp;
}

## • temp is a shared variable!

#pragma omp parallel for private(temp)
for(i=0; i<n; i++) {
    temp = 2.0*a[i];
    a[i] = temp;
    b[i] = c[i]/temp;
}
