Note: The user interface runs on the following web browsers: Google Chrome, Firefox, Microsoft Internet Explorer (version 11), Microsoft Edge, Safari (version 7 or higher).

### 2.4 User login

Login is done by clicking on the Login button and specifying the user name and password. The default login is admin and the default password is admin as well.
