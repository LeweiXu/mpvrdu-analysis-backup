## 3 Configure Antivirus

Antivirus scanning has a significant, detrimental effect on the performance of the cvi42 application. Typical studies can contain thousands of individual image files and the time needed to scan each of those files is significant. The following directories should be configured to be excluded from any antivirus configuration on both the cvi42 server and client:

Windows: C:\ProgramData\cvi42, D:\cvi42images\cvi42imagedb

Mac: /Library/Application/Support/cvi42, ~/Documents/cvi42 (normal, non-root installations)

## 4 Configure DICOM Networking (PACS Connections)

Users with 'Administrate PACS' permissions can set up the configuration for DICOM Networking/PACS connections. The admin port (default is 49697) must be used to access the Network tab of the Preferences Menu.
