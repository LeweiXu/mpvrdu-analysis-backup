active If reduced brightness is set to "active", then the display brightness is reduced automatically 5 minutes after the last beverage is dispensed. If the display brightness has been dimmed, the display returns to the selected brightness level when it is first touched. The second time a beverage button is touched, the corresponding beverage is dispensed.
