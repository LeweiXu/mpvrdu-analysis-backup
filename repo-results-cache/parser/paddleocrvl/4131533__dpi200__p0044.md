##### 6.7.1.1 Export Files to External Drive

Export ODiSI-specific files such as sensor directories, test data, and converted TSV files to an external flash drive or CD drive.

##### 6.7.1.2 Import Files from External Drive

Import ODiSI-specific files such as sensor directories, test data, and converted TSV files from an external flash drive or CD drive.

##### 6.7.1.3 Manage Configuration

The specific sensor combination on each channel, as well as Tare, Rekey, and color selection can be saved as a Configuration for the ease of setting up the same test with the same combination of sensors.

Load Configuration: Set up the ODiSI using previously saved parameters.

Save Configuration: Save the current parameters used to set up the ODiSI channels.

Default Configuration: Factory-installed configuration

Delete Configuration: Delete a user-defined configuration.
