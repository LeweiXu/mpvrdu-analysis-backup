Each task is performed by a list of workers (placed in a queue). Each worker has a function that returns specific angles for a step to be taken. The steps include going above the object, picking the object, moving to a safe position, going to the designated storage box of an item, and dropping the item. Before moving to the next task, a worker will await a confirmation from the microcontroller signaling that the previous task is completed. After the pick and place is completed, and if no remaining objects are to be dequeued, the robotic arm will return to its home position.
