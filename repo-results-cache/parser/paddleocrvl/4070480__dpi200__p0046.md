## Description

The T1441 series is a temperature controller for controlling heat trace systems in ordinary and corrosive environments. It is ideal for process temperature control and freeze protection.

## T1441X

## Features

- Cast aluminum. T1441 is NEMA 4 and T1441X is explosion proof for Class 1 Division 1 & 2, Groups C & D.

• Sheath is 1/4" OD Stainless Steel

• Operating range is  $ 0^{\circ} $F to  $ 700^{\circ} $F

• Element Type is  $ 100\Omega $, 3-Wire RTD, DIN 0.00385

• 1/2" entry

• Tolerance: Class B, ± 0.12%
