## Digital Marketing: Some Quick Definitions

### 5. Targets

Targets are numerical values you have pre-determined as indicators success or failure.

It is rare, even with the best intentions, that you'll create targets for all the metrics you'll report on. Yet it is critical that you create targets for each web analytics key performance indicator.
