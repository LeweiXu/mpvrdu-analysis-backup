#### 7.4.2 Verify IP Address Assignment from DHCP

Using the Dell Thin Client Application, verify the network connection status and the IP address assignment from DHCP.

To verify the IP address assignment from DHCP

1. Open the Dell Thin Client Application and click Client Information.

2. Scroll down to Network.

3. Verify that an IP address has been assigned as displayed in the following figure.
