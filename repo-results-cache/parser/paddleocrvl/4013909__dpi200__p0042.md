#### 13.4.5 Case Study: KF Design for Heading Autopilots

The main sensor components for a heading-controlled ship are:

• Magnetic and/or gyroscopic compasses measuring the yaw angle

• Attitude rate sensor (ARS) measuring the yaw rate

In many commercial systems only the compass is used for feedback control since the yaw rate can be estimated quite well by a state estimator.
