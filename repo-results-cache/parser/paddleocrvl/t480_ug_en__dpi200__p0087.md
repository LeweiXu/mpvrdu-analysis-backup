## • USB Key Provisioning

## • CIRA Timeout

Values: 0–255

Description: Set the timeout option for the CIRA connection to be established. Selectable values are from 0 to 255. If you select 0, use 60 seconds as the default timeout value. If you select 255, the waiting time for establishing a connection is unlimited.

Note: The default value is 60 seconds.
