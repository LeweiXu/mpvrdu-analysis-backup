## Highlight, Isolate, Unisolate

<div style="text-align: center;"><img src="imgs/img_in_image_box_652_1407_1048_1493.jpg" alt="Image" width="23%" /></div>


These commands can be used to view and administer the existing layer groups. Isolating will display only the components used in the current group. To display all the components of the current discipline, click the Unisolate button.

The Highlight command can be a useful tool in updating a layer group. For example, if you wish to add a few components to an existing layer group, instead of having to select all the components again, you can highlight them with this command and select the extra components needed to add to the layer group.
