## 6 Using the ODiSI 6 Software

This section describes in detail all the functionality of the ODiSI 6 Software.

### 6.1 Operational Parameters

When first launched, the user interface displays the system Status and Sensor Properties. Among other things, the “Sensor Properties” tab displays the current state of the system including information on the configuration of each channel and detailed information for each sensor.

#### 6.1.1 Instrument Status

The system Status is indicated in the top left corner, and is either one of the following:

- Initializing: The software has just been launched and is connecting to and configuring the hardware.

• Ready: The software is ready to start making measurements on HD-FOS sensors.

• Running Test: The system is currently making measurements for a test.
